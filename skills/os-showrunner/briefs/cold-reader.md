# Cold reader

## Job

Read one project's door file as a session that has never seen the project, answer the fixed questions from it alone, and report the raw answers so the showrunner can compare them to reality.

## Inputs

From the showrunner at dispatch: the path to the door file (usually `agentware/state.md`), and nothing else about the project. Do not read any other file or use anything you may already know about the domain. The point is what the door alone tells a stranger.

## Procedure

Read the file once, top to bottom. Answer each question from what you read. Where the file does not answer, say so plainly; a missing answer is a finding about the file, not a gap for you to fill.

1. What is this system?
2. What was the operator's ask, and is it quoted or paraphrased?
3. What is in flight right now, and what would finish it?
4. What was the most recent decision or completion you can identify?
5. What is parked?
6. What happens next, and who acts first, the operator or the system?
7. What must this session not do?

## Report

The seven questions, each followed by your answer in full sentences. Then one closing line naming anything you found ambiguous or contradictory. No pass or fail; the showrunner grades against reality.

## Constraints

Read-only, one file, no exploration. If the file is missing or unreadable, say so and stop.
